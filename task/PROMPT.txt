做 proofmarket，给一批需要多方证据的离线合规评审安排证据采购。输入是一张“做决策时能知道的”版本证据图。一个证据可能是叶子签收或由上游给出的复合承诺，承诺只在其所有引用前置承诺有效时覆盖声明区域。有些项可用任意两个独立实验室证据替代同一份完整年报，独立性按实际所有权合并区间计算；同一实验室拆成两个法律单位没有自动增加独立性。合并包的报价随同批次规模分段，并允许一份证据复用几十个控制项，批准的区域交集和证据真实覆盖而非报价范围决定能否复用。
实现 judge CASE EVIDENCE 输出每个控制项覆盖的精确时间并集、最小可核验反例以及首个不能证明的依赖。实现 buy，在最多 18 个采购动作上按全期费用、后续人工复核天数、采购条数及 ID 选唯一方案。另做 check，必须拒绝把同一控制项依赖的两个不同上游当作独立来源，以及同费用但人工复核天数更大的解。给出两个单买均收费较低但会失去不同组独立阈值的例子，另有临时母公司合并导致非相邻区间失效，宿主时轴跨度 10^9；用少量区间端点，不逐时刻遍历。
从空仓库实现，使用 Windows 普通 CPU 和 Python 3.12 标准库，全部离线。交付 UTF-8 JSON CLI、明确的输入格式、README、合成夹具及 unittest。
